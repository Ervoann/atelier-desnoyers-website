# Guide d'utilisation - Back-office Atelier Desnoyers

Bienvenue dans votre espace d'administration !

## Accéder au back-office

1. Allez sur : **https://votre-site.com/admin**
2. Cliquez sur **Login with GitHub**
3. Connectez-vous avec votre compte GitHub

---

## Modifier la page d'accueil

### Changer le titre et la bannière

1. Dans le menu, cliquez sur **Paramètres du site**
2. Cliquez sur **Page d'accueil**
3. Vous pouvez modifier :
   - **Titre du site**
   - **Sous-titre**
   - **Image de bannière** (cliquez pour uploader une nouvelle image)
   - **Description**

### Modifier les sections

Faites défiler jusqu'à **Sections** :
- Cliquez sur une section pour la modifier
- Cliquez sur **Add Section** pour ajouter une nouvelle section
- Utilisez la poubelle pour supprimer une section

**Sauvegardez** en cliquant sur **Publish** puis **Publish now**

---

## Créer un article de blog

1. Dans le menu, cliquez sur **Articles de blog**
2. Cliquez sur **New Article de blog**
3. Remplissez les champs :

### Champs obligatoires
- **Titre** : Le titre de votre article
- **Date de publication** : Choisissez la date et l'heure
- **Auteur** : Votre nom (par défaut : Atelier Desnoyers)
- **Image de couverture** : Cliquez pour uploader l'image principale
- **Contenu** : Écrivez votre article

### Champs optionnels
- **Résumé** : Court texte qui apparaîtra dans la liste des articles
- **Catégories** : Classez votre article (ex: Actualités, Tutoriels)
- **Tags** : Mots-clés pour votre article

### Publier ou sauvegarder en brouillon

- **Publié** : Cochez la case pour que l'article soit visible sur le site
- Décochez pour garder l'article en brouillon

### Enregistrer l'article

1. Cliquez sur **Publish** (en haut à droite)
2. Cliquez sur **Publish now**

**Votre article sera en ligne dans 2-5 minutes !**

---

## Modifier un article existant

1. Cliquez sur **Articles de blog**
2. Cliquez sur l'article que vous souhaitez modifier
3. Faites vos modifications
4. Cliquez sur **Publish** > **Publish now**

---

## Supprimer un article

1. Ouvrez l'article
2. Cliquez sur **Delete entry** (en haut à droite)
3. Confirmez la suppression

---

## Gérer les images

### Uploader une image

1. Dans n'importe quel champ image, cliquez sur **Choose an image**
2. Cliquez sur **Upload** et sélectionnez votre image
3. Ou glissez-déposez votre image directement

### Conseils pour les images

- **Format recommandé** : JPG ou PNG
- **Taille recommandée** :
  - Bannière : 1920 x 600 pixels
  - Image d'article : 1200 x 630 pixels
  - Image de section : 800 x 600 pixels
- **Poids** : Moins de 1 Mo par image si possible

---

## Informations de contact

### Modifier les coordonnées

1. Cliquez sur **Paramètres du site**
2. Cliquez sur **Paramètres généraux**
3. Modifiez :
   - Email de contact
   - Téléphone
   - Adresse
   - Liens réseaux sociaux

4. Cliquez sur **Publish** > **Publish now**

---

## Écrire en Markdown (pour le contenu des articles)

Le champ **Contenu** utilise Markdown, un format simple pour formater du texte :

### Titres
```
# Titre principal
## Sous-titre
### Petit titre
```

### Texte
```
**Texte en gras**
*Texte en italique*
```

### Listes
```
- Premier point
- Deuxième point
- Troisième point
```

### Liens
```
[Texte du lien](https://www.example.com)
```

### Images
```
![Description de l'image](/uploads/mon-image.jpg)
```

## Questions fréquentes

**Combien de temps avant que mes modifications apparaissent ?**
- Entre 2 et 5 minutes après avoir cliqué sur "Publish now"

**Puis-je annuler une modification ?**
- Non, mais vous pouvez toujours modifier à nouveau l'article

**Combien d'images puis-je uploader ?**
- Illimité, mais gardez vos images optimisées (< 1 Mo)

**Puis-je avoir plusieurs auteurs ?**
- Oui, chaque personne avec un compte GitHub peut se connecter
